# travel-assistant-1358-2580

This workspace contains the WeatherForecastService FastAPI application.

Navigate to `WeatherForecastService/` for service-specific documentation and to run the app.

Quick start:
- cd WeatherForecastService
- pip install -r requirements.txt
- uvicorn src.api.main:app --host 0.0.0.0 --port 3000 --reload
- Open http://localhost:3000/docs
